# main

## Overview
The production source set of the app: `AndroidManifest.xml` (activity, services, receiver, FileProvider and permissions), Java sources, and resources. `assets/` (the built web app, brand profiles, OCR data and Samsung catalog) is generated at build time and is not documented here; `res/` is resource-only.
